## ❓ 常见问题

### Q: 误删了重要文件怎么办？
A: 立即从git恢复：
```bash
git reset --hard HEAD^
# 或从数据库备份恢复
```

### Q: 清理会影响功能吗？
A: 不会！删除的都是：
- 开发时创建的临时文件
- 调试时的输出文件
- 历史数据快照
- 服务日志
**不影响任何生产功能。**

### Q: Demo页面删除吗？
A: 不一定。如果需要：
```bash
# 移动到docs目录
mv giro*.html docs/
mv giro_women*.html docs/
```

### Q: 为什么不直接删除？
A: 安全起见创建脚本，包含：
- 强制确认
- 详细列表
- 自动提交
- 日志记录
