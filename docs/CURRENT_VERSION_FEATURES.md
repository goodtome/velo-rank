# 当前版本功能整理

整理日期：2026-06-20  
项目：正一领骑 / velo-rank  
版本口径：以 `docs/V2.0.0_RELEASE_SCOPE.md` 为主，结合当前小程序页面与后端路由实现核对。

## 一、版本定位

当前版本聚焦“自行车赛事成绩追踪”，面向自行车运动爱好者提供赛事、赛段、成绩榜单、车手/车队信息查询。

赛事数据可视化已纳入当前版本范围，覆盖赛事详情页的赛程距离/类型/强度分析、赛程节奏视图、GC 时间差走势展示，以及车手详情页的近期表现轻量图。

## 二、对外用户功能

### 1. 首页

- 展示进行中赛事
- 展示近期完赛赛事
- 无进行中/近期赛事时，回退展示当前赛季赛事
- 支持首页数据本地缓存，提升首屏加载速度
- 支持点击赛事进入赛事详情

涉及页面：`miniprogram/pages/index`

### 2. 搜索

- 支持车手搜索
- 支持车队搜索
- 支持赛事搜索
- 赛事搜索支持按关键词、年份/赛季等条件查询
- 搜索结果可跳转车手详情、车队详情或赛事详情

涉及页面：`miniprogram/pages/search`

### 3. 赛事日历

- 按年月查看赛事日历
- 展示当月赛事
- 支持赛事日期状态识别
- 支持点击赛事进入详情

涉及页面：`miniprogram/pages/race-calendar`

### 4. 赛事归档

- 按年份筛选赛事
- 按赛事类型筛选赛事
- 按赛事状态筛选赛事
- 按关键词搜索赛事
- 展示匹配数量与快捷筛选入口

涉及页面：`miniprogram/pages/race-archive`

### 5. 赛事详情

- 展示赛事基础信息：名称、类别、性别、赛季、日期、总赛段、总距离
- 展示赛段列表
- 展示赛段路线、日期、距离、赛段类型
- 展示最新领骑衫归属
- 提供总成绩榜入口
- 提供冲刺、爬坡、青年、车队榜入口
- 已包含部分赛事结构分析：总距离、平均距离、长赛段数量、休息日、赛程密度、难度拆解、赛段类型分布、赛程时间线

涉及页面：`miniprogram/pages/race-detail`

### 6. 赛段成绩 / 分类榜

- 展示赛段成绩排名
- 展示总成绩榜 GC
- 展示车队成绩榜
- 展示冲刺积分榜
- 展示爬坡积分榜
- 展示青年车手榜
- 支持分页加载更多
- 支持从成绩行跳转车手详情
- 支持领骑衫展示
- 团队计时赛会优先展示车队榜
- GC 榜已包含时间差走势图

涉及页面：`miniprogram/pages/stage-results`、`miniprogram/pages/classification`

### 7. 实时成绩

- 支持 GC、赛段、冲刺、爬坡、青年五类实时结果视图
- 支持 WebSocket 订阅实时数据
- WebSocket 不可用时，仍可通过 HTTP 接口拉取数据

涉及页面：`miniprogram/pages/realtime-results`

### 8. 车手详情

- 展示车手基础资料
- 展示车手统计信息
- 展示车手历史成绩
- 支持跳转所属车队
- 支持成绩分页/限制查询

涉及页面：`miniprogram/pages/rider-detail`

### 9. 车队详情

- 展示车队基础资料
- 展示车队统计信息
- 展示车队车手列表
- 支持跳转车手详情

涉及页面：`miniprogram/pages/team-detail`

### 10. 个人中心

- 展示项目统计概览入口
- 整合赛事日历、赛事归档、推送设置、帮助反馈等入口
- 提供隐私政策、用户协议入口
- 支持账号删除
- 提供内部管理员同步入口

涉及页面：`miniprogram/pages/profile`

### 11. 推送设置

- 支持基础推送设置
- 支持赛事开始提醒
- 支持赛段结束提醒
- 支持关注车手排名变化提醒
- 支持关键事件提醒
- 支持订阅消息授权
- 支持测试推送

涉及页面：`miniprogram/pages/push-settings`

### 12. 百科与帮助

- 提供自行车赛事相关术语/百科内容
- 提供帮助反馈页
- 提供隐私政策与用户协议

涉及页面：`miniprogram/pages/encyclopedia`、`miniprogram/pages/help-feedback`、`miniprogram/pages/privacy-policy`、`miniprogram/pages/user-agreement`

## 六、版本边界建议

对外宣传建议聚焦：

- 赛事首页
- 赛事搜索
- 赛程日历
- 赛事详情
- 赛段成绩
- GC / 冲刺 / 爬坡 / 青年 / 车队榜
- 车手详情
- 车队详情
- 赛事归档
- 推送设置
- 中文化体验

不建议在 v2.0.0 对外突出：

- 管理员同步页：小程序端默认隐藏，只有本机已保存管理员密钥时显示入口
- 数据导入脚本：仅保留为内部维护工具，不提供用户入口
- 管理后台：必须通过管理员密钥访问
- 收藏/关注能力，除非小程序端也完成完整用户路径
