## 三、部分实现功能 ⚠️

### ⚠️ 1. 赛事数据覆盖严重不足

| PRD要求 | 当前状态 | 缺失 |
|---------|---------|------|
| UCI男子WorldTour | 仅环意2026（Stages 1-5） | 20+场WT赛事 |
| UCI女子WorldTour | 0 | **全部缺失** |
| 环法 Tour de France | 仅测试条目（2025） | 2026数据 |
| 环西 Vuelta a España | 0 | **全部缺失** |
| UCI公路世锦赛 | 0 | **全部缺失** |
| 近3年历史数据 | 0（仅2026） | 2024-2025 |

**影响**：这是v1.0最大的gap——PRD明确要求覆盖男子WorldTour+女子WorldTour+三大环赛+世锦赛，目前只有环意的5个赛段。

### ⚠️ 2. 数据同步自动化未完成

`POST /sync/races/:id` 是空的TODO桩：
```js
// server/routes/sync.js
router.post('/races/:id', async (req, res) => {
  // TODO: 添加认证中间件
  // TODO: 触发PCS爬取脚本
  res.json({ code: 200, message: '同步任务已提交，请查看同步状态' });
});
```
**影响**：数据录入目前完全依赖手动（admin后台录入），无法自动同步。

### ⚠️ 3. 离线缓存不完善

`wx.setStorageSync` 仅在部分页面使用，缺少统一的缓存策略：
- 浏览器端无Service Worker
- 赛段成绩页无离线缓存
- 缺乏缓存失效机制

## 四、缺失功能 ❌（v1.0范围内）

### ❌ 1. 赛事搜索 —— **P0缺失**

**PRD F-01 明确要求**：「按赛事名称、年份、赛段搜索」

| 现状 | 需要的 |
|------|--------|
| 搜索页只有「车手」「车队」两个Tab | 缺少「赛事」Tab |
| 无 `GET /search/races` API | 需新增端点 |
| 搜索页 `app.json` 配置为「车手搜索」「车队搜索」 | 需改为三个Tab或用统一搜索 |

**修复方案**：
1. `server/routes/search.js` 新增 `GET /search/races?q=&year=`
2. `miniprogram/pages/search/` 新增赛事搜索Tab
3. 搜索结果可点击跳转 `race-detail`

### ❌ 2. 车队成绩榜 —— **P1缺失**

**PRD F-02 明确要求**：「车队团体计时赛成绩」

当前完全没有车队成绩相关的API和页面。

**修复方案**：
1. 新增 `GET /races/:id/team-classification` API（车队累计时间排名）
2. 在 `race-detail` 页面新增「车队榜」Tab

### ❌ 3. 完赛率统计 —— **P2缺失**

**PRD F-02**：「完赛车手/发车车手比例」

**修复方案**：
1. 在 `GET /stages/:id/results` 响应中新增 `finish_rate` 字段
2. 赛段成绩页底部展示完赛率

### ❌ 4. 分享功能（赛事成绩海报图） —— **完全缺失**

**Tech Spec 5.3**：「生成赛事成绩海报图分享到朋友圈」

当前完全没有实现。微信小程序需要 `<canvas>` 绘制海报 + `wx.showShareImageMenu`。

**修复方案**：
1. 赛段成绩页新增「分享」按钮
2. 使用Canvas绘制包含前三名+领骑衫的海报图
3. 调用微信分享API

### ❌ 5. 赛段精彩瞬间 —— **缺失**

**PRD Section 3**：「精彩瞬间（图片/视频集锦）」

赛段成绩页没有此区域。由于自行车赛事图片版权敏感，建议v1.0跳过或使用免费图源。

### ❌ 6. 赛段天气信息 —— **缺失**

**PRD Section 3**：「赛段基本信息（距离、爬升、天气）」

`stages` 表有 `weather_summary` 字段但从未被填充，前端也未展示。

## 九、总结

**v1.0 PRD与代码实现的差距主要体现在三个方面**：

1. **数据覆盖** — 这是最大短板。PRD要求覆盖男子+女子WorldTour、三大环赛、世锦赛，目前只有环意男子的5个赛段数据。

2. **赛事搜索** — 这是v1.0明确要求的P0功能，但/ search/races完全缺失，搜索页只有车手和车队。

3. **自动化** — 数据同步是TODO桩代码，数据录入完全依赖手动操作。

**评估**：v1.0核心功能框架搭建完成（约70%），剩余关键缺口集中在数据层面和几个具体功能点。按一个人开发的速度，完成P0项约需 **2-3天**，P1项约需 **3-5天**。
