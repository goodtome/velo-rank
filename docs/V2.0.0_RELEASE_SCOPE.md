# v2.0.0 发布范围表

## 发布原则
- 本版本聚焦“赛事成绩追踪”主线。
- 已明确砍掉 `AI 成绩解读` 和 `骑行数据对比`。
- `赛事数据可视化` 作为下一阶段增强，顺延到 `v2.1`。
- `admin-sync` 属于内部运营支撑，不计入对外发布范围。

## 一、对外发布范围

| 模块 | 功能 | 说明 |
|---|---|---|
| 基础体验 | 全中文界面与本地化 | UI、术语、文案统一中文化 |
| 首页 | 赛事首页 / 推荐入口 | 展示重点赛事、快速入口 |
| 搜索 | 赛事搜索 | 支持按赛事名、代码、国家、赛季搜索 |
| 赛程 | 赛程日历 | 按月查看赛事日历与当天赛事 |
| 赛事详情 | 赛事基础信息 | 赛事名称、类别、赛季、日期、总赛段、总距离 |
| 赛事详情 | 赛段列表 | 查看所有赛段并跳转赛段成绩页 |
| 赛事详情 | 领骑衫展示 | 展示最新领骑衫归属 |
| 赛事详情 | 车队成绩榜入口 | 跳转整体车队成绩榜 |
| 成绩页 | 赛段成绩 | 展示赛段名次、时间差、积分等 |
| 成绩页 | 总成绩（GC） | 展示总成绩榜与领骑衫联动 |
| 成绩页 | 冲刺 / 爬坡 / 青年榜 | 展示分项分类榜单 |
| 成绩页 | 车队成绩榜 | 赛事级车队总排名 |
| 归档 | 赛事归档 | 按年份、类型、状态、关键词筛选赛事 |
| 归档 | 快速统计 | 当前匹配数量、状态快捷筛选 |
| 个人中心 | 入口整合 | 赛事归档、日历、推送设置等入口统一收口 |
| 推送 | 基础推送设置 | 赛事开始、赛段结束、关注车手排名变化、关键事件 |
