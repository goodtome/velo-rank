scrollToRider(e) {
  const { riderId } = e.currentTarget.dataset;
  const query = wx.createSelectorQuery();

  query.select('.race-list-container').boundingClientRect();
  query.select(`#rider-${riderId}`).boundingClientRect();

  query.exec((res) => {
    const scrollTop = riderRes[0].top - containerRect.top - 100;
    wx.pageScrollTo({ scrollTop, duration: 300 });
  });
}

## 重要提醒

### 安全性 ⚠️
1. **生产环境必须修改SESSION_SECRET**
   ```bash
   # 不要使用默认值！
   SESSION_SECRET=使用一个强随机字符串
   ```

2. **CORS配置**
   ```bash
   # 不要设置为 *
   CORS_ORIGINS=https://yourdomain.com
   ```

3. **密码策略**
   - 已使用bcrypt加密
